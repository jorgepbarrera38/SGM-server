# SGM – Backend

Backend desarrollado con Laravel para un Sistema de Gestión de Mantenimiento, orientado al registro, administración y seguimiento de los equipos y sus actividades de mantenimiento.

La solución permite centralizar la información técnica de los equipos mediante hojas de vida e historial de intervenciones, facilitando el control de su trazabilidad.

## Funcionalidades principales

- Registro y administración de equipos.
- Gestión de hojas de vida de los equipos.
- Registro de información técnica.
- Seguimiento de la trazabilidad de los equipos.
- Registro de actividades de mantenimiento.
- Consulta del historial de mantenimientos.

## Tecnologías utilizadas

- **Lenguaje:** PHP.
- **Framework:** Laravel 8.
- **Base de datos:** MySQL.
- **Autenticación:** JWT.
- **Generación de documentos PDF:** Laravel DomPDF.
- **Unión de documentos PDF:** Lara PDF Merger.
- **Exportación de información a Excel:** Maatwebsite Excel.

## Arquitectura

Este repositorio contiene el backend de una aplicación que expone servicios mediante una API REST, consumida por una interfaz desarrollada con Vue.js.
